# Dunlin 受け入れ確認

[受け入れ条件 §22](dunlin-spec.md#22-受け入れ条件) に対応する基本機能の確認結果です。Windows x64 で CLI、stdio MCP、Chromium、npm 配布物を確認しました。モデル応答はローカルの模擬サーバーを使用しています。

統合版 (2) の初期化、`ask`、検索の共通 JSON、HTTP 提供と接続制限は、Windows x64 で追加確認しました。自動テストでは回答モデルを模擬し、MCP TypeScript SDK で接続しました。別途、ローカル Ollama の `qwen3:4b` で CLI と OpenAI Node SDK から回答と出典を取得しました。[統合版 (2) §27](dunlin-spec.md#27-search-と-ask-の返却形式種別-rag-の-serve)
