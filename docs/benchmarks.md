# キーワード検索のベンチマーク

`benches/keyword.mjs` は Node.js API で合成 Markdown を登録し、同一プロセスからキーワード検索を順次実行します。検索語には文書ごとに異なる識別子を含め、正解は対応する文書1件とします。

## 再現する

```sh
npm run build
npm run bench -- 1000 300
npm run bench -- 10000 300
```

第1引数は文書数、第2引数は計測する問い合わせ数です。索引付きストアを開き直した後、初回の検索を単独で計測し、後続の上位10件検索で p50・p95・p99 を測ります。`ingestMs` は生成済み資料の読み取りと索引登録にかかった時間です。`rssMiB` は計測終了時のプロセス全体の RSS です。

## Windows x64 での実測

2026年11月15日、コミット `5a310c6` のチェックアウトで各規模を1回ずつ順に実行しました。環境は Windows 11 Pro 10.0.26300、AMD Ryzen AI Max+ 395（16コア、32スレッド）、メモリ約64 GiB、Node.js 22.17.1 です。

| --- | --- | --- | --- | --- | --- | --- | --- |
