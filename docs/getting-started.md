# 入門：資料を、AI が引ける知識にする

[English](getting-started.en.md)

Knowledge-Nest を初めて使う人のための入口です。やりたいことを1つ選び、その入門に進んでください。どれも、手元の資料フォルダ1つから始められ、プログラムは書きません。

## 1 やりたいことから選ぶ

| やりたいこと | AI モデル | 入門 |
|---|---|---|
| **Claude などのエージェントに、手元の資料を調べさせたい** | 要らない | [MCP 入門](start-mcp.md) |
| **自分のアプリやチャットボットに、出典付きの答えを返させたい** | 回答に要る | [RAG 入門](start-rag.md) |
| **資料を、チームで使う知識のページにまとめたい** | 執筆に要る | [Wiki 入門](start-wiki.md) |
| **自分の仕事の資料とメモを、自分の取り組みごとに整理したい** | 執筆に要る | [PARA 入門](start-para.md) |

- **迷ったら1つ目から。** モデルの準備が要らず、数分で試せます。同じ資料から、あとでほかの形も作れます。
- **Wiki と PARA は、どちらも資料の整理だが目的が違う。** Wiki はみんなが使う知識を「何についてか」でまとめ、PARA は自分の仕事の資料を「どの取り組みに使うか」で整理します。
- **どれも出典付き。** 検索結果も、答えも、ページも、元の資料を指します。

ほかの道具と比べてどこが違うか、4つの形がどう違うかは、[4つの形の違い](forms.md) と [Knowledge-Nest が向いている構成](comparison.md) にあります。

## 2 用意するもの

- Knowledge-Nest のインストール。いまはソースからのビルドです。手順は [README のインストール](../README.md#インストール) にあります。`nest --help` が表示されれば準備完了です。
- 資料を入れたフォルダ。手元にない場合は、リポジトリに同梱の [examples/manuals](../examples/manuals/maintenance.md) を使えます。ポンプの保全手順を書いた短い Markdown です。
- 2つ目から4つ目では、AI モデルが要ります。入門では、手元で動く Ollama の `qwen3:4b` を使います。

4つをサンプル資料で一度に試すなら、[サンプル資料で始める](quickstart.md) もあります。
