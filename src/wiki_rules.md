# 運用の決まり

この Wiki は、資料を AI が読んでページにまとめ、資料が増えるたびに書き足していくものです。AI はこの決まりに従ってページを書きます。使いながら、この決まりも直していきます。

## 3つの層

- **原本**（`raw/`）：集めた資料。AI は読むだけで、書き換えない。
- **ページ**（`wiki/`）：AI が書いて保つ。人は読んで、方向を決める。
- **決まり**（`rules.md`）：このファイル。ページの構成と書き方を決める。人が書いて直す。AI は分類の一覧に新しい分類を足すだけで、ほかは書き換えない。

## 分類

ページは、何についてのページかで分類する。ページの種類（要約、用語など）では分けない。目録はこの分類の順に並ぶ。

分類の一覧は、AI が足し、人が整える。取り込みで、AI がこの分類のどれにも当てはまらないページに新しい分類を付けたときは、その分類がこの下に足される。AI は足すだけで、分類を消したり、名前を変えたりはしない。分類は、いくつものページがまとまる広さにする。似た分類をまとめる、名前を変える、並べ替えるときは、人がここを書き換える。一覧から外れた分類のページは `nest lint` が `UNKNOWN_CATEGORY` として示すので、`nest instruct <ページ> --category <分類>` で付け替える。各ページの分類は、ページのファイルの末尾の JSON の `category` にある。

## ページ

- ページ ID はフォルダを付けない名前にする（例：`かんばん`）。
- 資料に出てくる人・組織・もの、考え方・手法・用語は、それぞれのページにまとめる。
- ほかのページにまとめきれない、その資料ならではの内容（主張、経緯、事例など）があるときは、その資料の要約ページを作る。ID は `要約-` のあとに資料の名前（`name`）を拡張子なしで付ける（例：`要約-スクラムガイド`）。何の資料か、要点は何かを書き、関係するページへリンクする。
- 全体をまとめるページ（見取り図、概要）は作らない。全体は目録（`wiki/index.html`）で見る。

## 書き方

- ページは Markdown で書く。最初の文で、そのページが何についてのものかを言う。目録にはこの文が載る。
- 資料にあることだけを書く。数字・日付・名前・引用（「」）は資料のとおりに書く。`lint` が、資料にないものを指摘する。
- ページの末尾には、書くのに使った資料が出典として並ぶ。文ごとの出典は付けない。
- 関係するページへは `[題名](/ページID)` でリンクする。どこからもリンクされないページを作らない。
- 新しい資料が前の記述と食い違うときは、前の記述を消さず、食い違うことをそのページに書く。

## 資料を取り込むとき

1. 資料に出てくるもの・考え方のページを、あれば書き足し、なければ作る。
2. その資料ならではの内容があれば、要約ページを書く。
3. Wiki に足すことのない資料（すでに書いてあることだけの資料、目的に関係のない資料）では、ページを書かない。その資料は「得るものなし」として記録に残る。
